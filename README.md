# لوحة بيانات الفحوصات الطبية العالمية (Global Medical Testing Analytics Dashboard)

لوحة بيانات تحليلية تفاعلية (Power BI / Cybernetic HUD Style) مصممة باللغة العربية بالكامل مع دعم تنسيق النصوص من اليمين إلى اليسار (`RTL`) وتوافق كامل مع شاشات الجوال وسطح المكتب. تجمع اللوحة بين التصميم البصري المتقدم (Emerald & Cyan Holographic HUD) وتحليل البيانات الحقيقية المتصلة بواجهة بيانات **البنك الدولي الحية (World Bank Open Data REST API v2)** وسجلات صفقات الاستحواذ الطبية والتشخيصية العالمية الموثقة.

---

## أبرز المميزات (Key Features)

1. **خريطة الكرة الأرضية التفاعلية ثلاثية الأبعاد (`3D Holographic Data Globe`)**:
   - رسم ثلاثي الأبعاد للقارات بنظام المصفوفة النقطية (`Dot-Matrix Continents`) مع شبكة الأبراج المضيئة وأقواس الربط العابرة للقارات.
   - **أعمدة ارتفاع البيانات ثلاثية الأبعاد (`3D Radial Investment Spikes`)**: تبرز فوق كل مركز إقليمي (طوكيو، حيدر آباد، بوسطن، ميونخ، موسكو، شنغهاي) بارتفاع يتناسب طردياً مع حجم الاستثمار بالمليون دولار.
   - **دوران الكاميرا الذكي (`Mathematical Camera Lock-On`)**: عند اختيار أي دولة أو صفقة من الجداول أو المخططات، تدور الكرة الأرضية تلقائياً لتضع تلك الدولة في مركز الرؤية مع بطاقة قياس حيوي فورية (`Live Telemetry HUD`).

2. **خوارزمية التنبؤ باتجاه الاستثمار للشهر القادم (`OLS + EWMA Time-Series Forecasting`)**:
   - لوحة فرعية مدمجة داخل قسم **«نظرة عامة»** تطبق نموذجاً رياضياً يجمع بين **الانحدار الخطي للمربعات الصغرى (`Ordinary Least Squares Linear Regression`)** و**المتوسط المتحرك الموزون أُسّياً (`EWMA`)** على بيانات السلاسل الزمنية المسجلة.
   - تعرض **النسبة المتوقعة للشهر القادم (`%`)**، **التدفق المالي الشهري المتوقع (`$M`)**، **معامل الثقة الإحصائي (`R² Confidence %`)**، ومخطط مسار التنبؤ المصغر (`Sparkline T+1`).

3. **مقسمات تحليل البيانات بأسلوب Power BI (`Interactive BI Slicers & Cross-Filtering`)**:
   - شريط تحكم علوي يتيح التصفية المتقاطعة الفورية حسب **الدولة**، **القطاع الصناعي** (*البحث والتطوير، الإنتاج الحيوي، البرمجيات الطبية، المبيعات والتوزيع*)، و**السنة** أو **الفترة الزمنية** (`2015–2018` و`2021–2024`).
   - تتحدث جميع المخططات الخمسة، أرقام النظرة العامة، خوارزمية التنبؤ، وجدول الصفقات فورياً عند تغيير أي فلتر.
   - إمكانية **تصدير التقرير (`CSV Export`)** بترميز `UTF-8 BOM` المتوافق مع Microsoft Excel وPower BI باللغة العربية.

4. **نافذة إثبات ومصادر البيانات الحية (`Live API & Data Lineage Proof Modal`)**:
   - توثيق حي لنقاط اتصال واجهة **البنك الدولي (`World Bank API v2`)** للمؤشرين:
     - `SH.XPD.CHEX.GD.ZS`: الإنفاق الصحي كنسبة من الناتج المحلي الإجمالي (`% of GDP`).
     - `SH.XPD.CHEX.PC.CD`: حصة الفرد السنوية من الإنفاق الصحي بالدولار الأمريكي (`Per Capita USD $`).
   - عرض أرقام القيد التنظيمية لصفقات الاستحواذ (`SEC / TYO / Eurofins Filing IDs`) وشهادات الاعتماد الطبي (`FDA 510(k)`, `ISO-15189`, `PMDA`, `CE-IVD`) وعينة الاستجابة الخام (`Raw JSON Payload`).

## هيكلية المشروع (Project Structure)

```text
├── index.html                              # نقطة الدخول مع إعدادات RTL وخطوط Cairo و IBM Plex Mono
├── metadata.json                           # بيانات تعريف التطبيق
├── package.json                            # الحزم والاعتماديات (React 19, Vite, Tailwind CSS v4)
└── src/
    ├── App.tsx                             # المكون الرئيسي وإدارة الحالة والتصفية المتقاطعة (Cross-Filtering)
    ├── index.css                           # تنسيقات Tailwind CSS v4 والخطوط الرقمية أحادية المسافة
    ├── main.tsx                            # تشغيل تطبيق React
    ├── data/
    │   └── medicalTestingData.ts           # نماذج البيانات، السلاسل الزمنية، صفقات الاستحواذ، وإحداثيات المراكز
    └── components/
        ├── TopBannerHeader.tsx             # الترويسة السداسية العلوية وشرائط الأفق المضيئة
        ├── PowerBiControlBar.tsx           # شريط مقسمات التحليل (BI Slicers) وتصدير CSV وفحص API
        ├── InvestmentForecastPanel.tsx     # خوارزمية التنبؤ باتجاه الاستثمار للشهر القادم (OLS + EWMA)
        ├── HolographicGlobe.tsx            # الكرة الأرضية التفاعلية ثلاثية الأبعاد وأعمدة البيانات
        ├── HudCharts.tsx                   # المخططات البيانية الخمسة (Spline, Area, Bar, Butterfly, Rose Donut)
        ├── SectionHeader.tsx               # عناوين الأقسام بالنمط السيبراني الأخضر مع الشرطات المائلة (////)
        └── ApiProofModal.tsx               # نافذة تدقيق البيانات الحية وعرض JSON الخام من البنك الدولي
```

## طريقة التشغيل محلياً (Getting Started)

1. **تثبيت الاعتماديات**:
   ```bash
   npm install
   ```

2. **تشغيل خادم التطوير** (يعمل على المنفذ `3000`):
   ```bash
   npm run dev
   ```

3. **فحص الأنواع وبناء نسخة الإنتاج**:
   ```bash
   npm run lint
   npm run build
   ```
